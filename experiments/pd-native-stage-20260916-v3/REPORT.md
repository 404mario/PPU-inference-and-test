# P/D＋原生 STATIC DSpark：16 / 24 卡阶段实验

**两种拓扑均完成了请求链路和容量初筛；尚不能判定 D16 更优，生产服务生命周期也未通过验收。** 本轮用于了解 P/D 分离后的阶段行为，为后续部署筛选准备证据。P 处理输入，D 生成输出，D16 的专家分布在两个节点。没有在本轮运行 64 卡配比扫描或自定义动态预算策略。

合计 **336 次请求、88 个不同题目 ID**，并非 336 道独立题。全部请求传输完整且 usage 计数校验通过，评分器异常为 0。按既定规则，全部请求为 **133 正确 / 151 错答 / 52 未评分**；其中 240 次容量请求为 **71 / 129 / 40**。简答采用严格匹配，正确改写也可能被判错；代码没有执行单测，始终记为未评分。48 次合成功能检查通过不能替代自然质量评估。

模型为 DeepSeek-V4.1-Flash；固定原生 STATIC DSpark，gamma=5、窗口=6，attention TP=1（每个注意力组单卡计算）。上下文上限 32,768 token，关闭图执行和前缀复用。实际是 FP4 专家权重、FP8 激活量化再重建为 BF16 的厂商算子桥接路径，以及 FP8 KV 缓存；不能描述为全 BF16 或已证明与官方完整模型数值等价。详细并行、缓存预算与版本见 [deployment-config.json](deployment-config.json)。

## 容量初筛结果

C 是整个服务允许的并发请求数。下表速度均为整条服务的合计，分母包括停止新增请求后的排空时间；正确、错答、未评分的完整响应均计入完成请求/s 和输出 token/s。**这些不是 SLO 有效吞吐**，即尚未统计“满足指定延迟要求的请求数/秒”。两种拓扑卡数不同。

每点采用有界闭环请求：当前请求结束才补下一条，目标至少 180 秒且完成 30 条，接收新请求最长 480 秒，再排空在途请求。D8 的 C1 只有 25 条，未达到最低数量；其他点也仅达到初筛要求。没有做三次正式重复，各点都少于 100 条，不支持可靠的生产 p99 结论。D8 C16 与 D16 C8 各有一条输出达到长度上限。

**同样输入产生不同长度的答案，是当前比较的关键限制。** C8 两边提交了完全相同的 37 条请求，但输出总量为 2,204 对 3,766 token，只有 22 条输出文本相同。D16 的 token/s 较高，同时请求/s 较低、总耗时较长，因此不能直接宣布加速。C1、C16 的实际提交题目数也不同；其共享题目分别为 25、55 道。答案变化的原因尚未确定，不能归因于某个算子或并行机制。

自然负载来自公开文档问答、多选及基础 Python 编码，实际输出通常很短。300 条标定题库被按固定顺序前缀采样，各点没有强制相同长度配额；另备的 300 条自然评测题库本轮未用。详见 [WORKLOAD.md](WORKLOAD.md)、[逐阶段长度分布](data/phase-summaries.json) 和 [精确统计及配对结果](results.json)。这些短输出初筛结果与此前合置长输出基线的口径不同，不应直接相除得出 P/D 收益。

## 服务关闭异常与指标覆盖

D16 最后一条请求于 **13:03:54.641** 完成，测量排空结束于 **13:03:54.644**。D16 从节点首次调度器异常出现在 **13:04:01**：通信连接重置后调度器退出，非首节点随后进入 HTTP 启动分支，触发 `sglang:func_latency_seconds` 指标重复注册，以退出码 3 结束。异常发生在测量请求排空之后，已完成的客户端请求仍有独立完整回执；但这说明服务关闭生命周期有缺陷，不能称稳定服务验收通过。P/D 主进程的 137 是主动清理的终止结果，本轮不据此判断 OOM。

可追溯原件：从节点日志 `src-a084b054d12af9febd056074`（第 4352 行起）、D 主节点停止回执 `src-94e8d771a67109e0284be583`、控制器终态 `src-6848fec3ea3ee810d156e756`。来源散列见 [provenance.json](data/provenance.json)，原始日志保留在非公开归档。

监控共导出 **2,036,835 个白名单数值样本**。D8 的 P、D 各 194 份快照；D16 的 P、D 主节点、D 从节点各 214 份，后者共 642 份且无采集错误文件。从节点每次覆盖 DP8–15，最大采集间隔约 10.680 秒。最后一次快照在最后请求结束前 **3.555 秒**，缺少排空后的最终采集，故直方图末值不能当作完整阶段累计量；客户端请求计时独立保留。传输指标可能含排队、同步和完成通知，不能直接当作纯 DMA 时间。
